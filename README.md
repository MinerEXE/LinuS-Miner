# 🀄 Zen Mahjong

Classic **mahjong solitaire** (tile-matching) as a single-page HTML5 game —
**100% free, no advertisements, no in-app purchases, no tracking, fully offline.**

![Game](icons/icon.svg)

## Features

- **Three board sizes**: Small (48 tiles, extra-large tiles — great for beginners and
  anyone who wants bigger tiles), Medium (84), and the classic 144-tile turtle
- **Big, readable UI**: large tiles, large buttons, plain-language labels
- **Built-in "How to play" tutorial** shown on first launch (and any time via the ? button)
- **Friendly guidance while playing**: the selected tile lights up gold and all matching
  tiles glow; tapping a blocked tile flashes red and explains why; mismatches are explained too
- **Every deal is guaranteed solvable** (boards are generated by playing the game in reverse)
- **Undo**, **Hint** (cycles through available pairs), and **Shuffle** for stuck boards
- Timer with per-board best-time memory, live tiles/pairs counters
- Touch-first canvas renderer — portrait and landscape; the wide classic board
  auto-rotates 90° on tall phone screens so tiles stay big
- Ghost-click protection on dialogs (a fast final tap can't accidentally press a button)
- Installable **PWA**: full-screen, offline, home-screen icon on Android
- Zero dependencies, zero network requests — one HTML file plus a service worker

## Run it

Any static file server works:

```sh
python3 -m http.server 8080
# then open http://localhost:8080
```

(Opening `index.html` directly also works — you just lose the offline service worker, which requires http/https.)

## Get it on your Android phone

### Option 1 — Install as an app (easiest, no build tools)

1. Host the folder anywhere with HTTPS (GitHub Pages is free: *Settings → Pages → deploy from branch*).
2. Open the URL in **Chrome on Android**.
3. Tap **⋮ → Add to Home screen → Install**.

It installs like a normal app: its own icon, full screen, works in airplane mode. No ads, ever.

### Option 2 — Build a real APK from the PWA

Use [PWABuilder](https://www.pwabuilder.com) (paste your hosted URL, download the Android package), or
[Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) from the CLI:

```sh
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://YOUR-URL/manifest.webmanifest
bubblewrap build          # produces app-release-signed.apk
```

### Option 3 — Wrap with Capacitor (no hosting needed, fully local APK)

```sh
npm i -D @capacitor/cli @capacitor/core @capacitor/android
npx cap init "Zen Mahjong" com.example.zenmahjong --web-dir .
npx cap add android
npx cap open android      # build/run from Android Studio, or: cd android && ./gradlew assembleDebug
```

## How to play

Tap two matching **free** tiles to remove them. A tile is free when nothing rests
on top of it and at least one long side (left or right) is open.
All 34 standard kinds match their identical twins; the four **flowers** match each
other, and the four **seasons** match each other. Clear all 144 tiles to win.
